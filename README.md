# 🌲 SylvaTech — Website da Equipe

Website institucional da equipe **SylvaTech**, desenvolvido para apresentar o projeto **SylvaAI**, um sistema inteligente de detecção de ninhos da vespa-da-madeira em plantações de pinus utilizando análise de imagens e inteligência artificial.

---

## 🚀 Sobre o Projeto

O **SylvaAI** é uma solução voltada ao monitoramento florestal, permitindo a identificação automatizada de focos de infestação por meio de imagens capturadas em campo. O sistema utiliza tecnologias modernas e integração com inteligência artificial para auxiliar produtores e técnicos na tomada de decisão.

---

## 🧠 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Firebase (Authentication, Firestore, Storage)
- TensorFlow.js
- YOLO (em fase de integração)
- Chart.js
- Figma
- Git & GitHub

---

## 🎯 Objetivo

Apresentar a equipe, o projeto SylvaAI e as tecnologias utilizadas, servindo como vitrine institucional e portfólio acadêmico.
